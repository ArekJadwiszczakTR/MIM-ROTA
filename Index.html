Connect this rota

This standalone copy has no SharePoint/Cowork behind it - instead it stores its data as a file in a public GitHub Gist, identified by a "Sync ID" everyone on your team enters once. Viewing needs nothing further - anyone with the Sync ID can see the rota. Saving changes needs a GitHub Personal Access Token - each editor creates their own (free, ~2 minutes, scoped to just "gist" access) and it's stored only in their own browser, never shared or written into this file.
